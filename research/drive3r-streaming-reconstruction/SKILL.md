# Drive3R：分块流式几何基础模型（长程驾驶场景重建）

## 何时使用

- 用户问「长程/公里级驾驶场景重建怎么做」「流式几何基础模型」「VGGT 怎么处理长视频」
- 涉及长序列重建中的**尺度漂移 / 轨迹漂移 / 误差累积**问题
- 讨论「离线全双向 vs 逐帧因果流式 vs 分段重建后对齐」的范式取舍
- 要给自动驾驶 3DGS / 数字孪生 pipeline 选几何初始化方案

## 一、要解决的问题

端到端自动驾驶需要闭环仿真，3DGS 数字孪生是主流，但 3DGS 需要**稠密几何初始化**（LiDAR 太稀疏）。几何基础模型（VGGT 系）前馈一次就出稠密点云，但**一条驾驶日志动辄上千帧**：

- 全局注意力复杂度二次方 + 显存限制 → 整段离线推理直接 OOM
- 逐帧因果流式（StreamVGGT / CUT3R / TTT3R / DVGT-2）丢掉双向上下文 → 小误差持续累积，导致**尺度漂移 + 轨迹漂移**
- 分段重建后对齐（chunk-then-align，DA3-Nested / VGGT-Long / π-Long）块内有双向注意力，但切分刚性、块间无特征传递，只能靠重叠区后处理硬对齐

Drive3R 的定位：**保留块内双向推理 + 块间流式特征传递 + 按需主动重锚定**。

## 二、问题形式化

输入长时环视图像流 $\mathcal{I}_{1:T}=\{I_{t,v}\mid t=1..T,\ v=1..V\}$，每张图附带标定内参 $K_{t,v}$ 与相机到车体外参 $T^{\mathrm{ego}}_{t,v}$。目标在线预测车体轨迹 $\{E_t\}_{t=1}^{T}$ 与与多相机观测对齐的稠密点云 $\{P_{t,v}\}_{t=1,v=1}^{T,V}$。

与通用重建的三个差异（论文明确列为「自动驾驶先验」）：
1. 序列远超短片，必须长程流式；
2. 下游仿真要求**公制绝对尺度**一致，不能只恢复相对结构；
3. 平台提供稳定标定参数，可作为显式几何先验注入（通用场景反而要去估）。

## 三、架构（四段）

### 3.1 内参感知编码
ViT 编码 patch token 后，把 $K_{t,v}$ 转成**归一化相机射线嵌入（camera-ray embedding）**加到视觉 token 上，给稠密 3D 预测提供显式投影几何先验。

### 3.2 时空解码器（交替注意力）
- **intra-view spatial attention**：单相机图像内建局部上下文
- **inter-block spatio-temporal attention**：跨所有相机视图 + 时间上可用的块传播信息

### 3.3 任务分支
稠密点云分支、公制尺度分支（把归一化几何映射到真实尺度）、辅助相机位姿分支（仅训练期监督）、**车体位姿分支**（用 $T^{\mathrm{ego}}_{t,v}$ 作 rig 几何先验把多相机特征聚合到统一车体系）、**块级置信度分支**（重锚定触发信号）。

### 3.4 分块流式核心

**分块定义**（第 $b$ 块，每块 $K$ 帧）：
$$
\mathcal{B}_b=\{(t,v)\mid t=(b-1)K+1,\dots,\min(bK,T),\ v=1..V\},\quad b=1..\lceil T/K\rceil
$$

**块式因果掩码**（训练时一次前向跑多块，掩码保证训练与推理的信息访问模式一致）：
$$
M(q,k)=\begin{cases}0, & b(k)\le b(q)\\ -\infty, & b(k)>b(q)\end{cases}
$$
块内（跨时间跨相机）全互可见，未来块屏蔽。

**KV 缓存流式推理**：第 $b$ 块 query 同时关注本块 KV 与历史缓存 KV，处理完把自己 KV 追加进缓存：
$$
K_{\le b}^{(\ell)}=\mathrm{Concat}\big(K_{<b}^{(\ell)},K_b^{(\ell)}\big),\quad V_{\le b}^{(\ell)}=\mathrm{Concat}\big(V_{<b}^{(\ell)},V_b^{(\ell)}\big)
$$
避免每来新块重算全历史。

## 四、置信度感知重锚定（本文最关键的创新）

**动机**：KV 缓存只能减缓误差累积，无法阻断。历史缓存里的隐式几何状态会逐渐偏离当前观测 → 轨迹漂移、点云错位。

**块级置信度**：轻量 decoder 提取当前块的几何状态特征 → 空间与相机维度聚合 → 输出一个标量 $c_b$。注意它**不是**逐像素重建质量，而是「长程流式状态是否还可靠」的控制信号。

**自适应缓存重置**：$c_b\ge\tau$ 继续复用缓存；$c_b<\tau$ 丢弃整个 KV 缓存，从当前块附近的**重叠帧**重新起一段局部序列。重启位置由模型自己预测，而非固定块长切分——这是与 chunk-then-align 的本质区别。

**SE(3) 重锚定**：用重叠帧集合 $\Omega_b$ 上新旧两段的预测位姿求刚体变换把新段接回全局坐标系：
$$
R_b^{\star}=\Pi_{\mathrm{SO}(3)}\Big(\tfrac{1}{|\Omega_b|}\sum_{i\in\Omega_b}R_i^{\mathrm{old}}(R_i^{\mathrm{new}})^{\top}\Big),\qquad
t_b^{\star}=\tfrac{1}{|\Omega_b|}\sum_{i\in\Omega_b}\big(t_i^{\mathrm{old}}-R_b^{\star}t_i^{\mathrm{new}}\big)
$$
$\Pi_{\mathrm{SO}(3)}$ 为投影到最近合法旋转。变换作用于新段的位姿与点云。

**置信度监督信号（可复用技巧）**：以序列段首帧为参考帧，算预测与 GT 的相对位姿差（平移+旋转加权）→ 块内平均得 $e_b$ → 软标签
$$
y_b=\exp(-\alpha_{\mathrm{conf}}e_b),\quad \alpha_{\mathrm{conf}}=25
$$
损失为 $\mathcal{L}_{\mathrm{conf}}=\mathrm{BCEWithLogits}(s_b,y_b)$。**用轨迹漂移当自监督信号训一个「什么时候该不信自己」的分类头** —— 这个思路可直接迁移到任何长序列流式重建/VO。

## 五、损失

沿用 π³x 的几何监督：$\mathcal{L}_{\mathrm{geo}}$（point map + depth，有效像素）、$\mathcal{L}_{\mathrm{scale}}$（公制尺度）、$\mathcal{L}_{\mathrm{cam}}$（辅助相机位姿）、$\mathcal{L}_{\mathrm{ego}}$（平移误差 + 测地旋转误差）、$\mathcal{L}_{\mathrm{conf}}$。

## 七、局限与批判性读法

1. **15 帧位姿不占优**（Waymo ATE 3.94 vs 离线 VGGT 3.21），论文的位姿收益只在长序列场景兑现，不能一概而论。
2. **τ 阈值未在正文给具体数值**，且「置信度过低 → 丢缓存重来」在极端场景（长隧道、无纹理高速、大雾）可能频繁触发，重置次数与轨迹抖动的关系没有量化报告。
3. **重锚定依赖重叠帧**：若触发点恰好重叠不足或无有效对应，SE(3) 对齐的鲁棒性存疑（论文未给失败案例分析）。
4. **公制尺度分支 + 标定外参强依赖**：跨车、跨数据集迁移时标定误差会直接进几何；论文只在 nuScenes/Waymo/KITTI 三个标定良好的数据集验证。
5. **无动态物体建模**：交通参与者仍在点云里，没做动/静态分离，而仿真恰恰需要动态参与者可编辑。这是通向 3DGS/闭环仿真的下一步（作者自述 future work）。
6. 基线与评测协议均为「统一输入协议 + 统一指标管线」，DVGT-2 等基线是作者复现版本，跨论文比数字时要留余地。

## 八、可迁移的工程要点

- **训练/推理一致性**：用块式因果掩码在训练时单次前向跑多块，等价于推理期 KV 缓存的信息访问模式。任何「训练用全注意力、推理用流式」的模型都会有 train-test mismatch，这是干净解法。
- **KV 缓存必须能被主动清空**：长期流式系统的缓存是无界增长的状态，StreamVGGT 的 OOM 是设计缺陷不是工程问题。给缓存配一个「该丢了」的判据 +
  重连机制。
- **用下游误差当自监督标签**：$y_b=\exp(-\alpha e_b)$ 把「轨迹漂移」这种不好直接监督的量变成置信度软标签，BCE 训练。VO / SLAM / 长时定位都能借。
- **重锚定而不是硬切分**：chunk-then-align 的刚性边界会切断连续运动，让模型决定切哪里（自适应）比对数据决定（固定 K）更合理。
- **先验显式注入**：内参→相机射线嵌入、外参→车体系聚合，比让网络隐式学投影几何省力得多，驾驶数据天然具备这些先验。
